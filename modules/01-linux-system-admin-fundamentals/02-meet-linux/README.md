# Topic 02: Meet Linux

**Module:** 01-linux-system-admin-fundamentals  
**Topic Sequence:** 2 of 8  
**Status:** In Progress  

---

## 1. Overview & Scope
Linux history, open-source licensing, kernel vs user space architecture, the UNIX philosophy, and core command line interface principles.

---

## 2. Learning Objectives
- Explain the relationship between the Linux kernel, system libraries, and the shell
- Understand the UNIX philosophy: small programs doing one thing well
- Navigate the CLI efficiently using command history, tab completion, and built-in help

---

## 3. Core Commands Reference

| Command | Operational Purpose |
| :--- | :--- |
| `whoami` | Print effective user ID |
| `hostname -I` | Display host IP addresses |
| `uptime` | Show system uptime and load average across 1, 5, and 15 minutes |
| `man [command] / [command] --help` | Access authoritative reference manuals and synopsis |
